# Sicherheit

Sicherheitsprobleme bitte nicht als öffentliches Issue melden. Verwende dafür
auf GitHub **Security → Report a vulnerability**. So kann der Bericht zunächst
vertraulich geprüft werden.

Bitte füge nur die Informationen bei, die zur Reproduktion notwendig sind, und
entferne Zugangsdaten, Tokens, private Schlüssel sowie personenbezogene Daten.
